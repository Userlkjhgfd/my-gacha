MY GACHA — iPhone向けホーム画面Webアプリ

ファイル:
- index.html: アプリ本体
- manifest.json: ホーム画面追加用の設定
- sw.js: オフライン用キャッシュ

重要:
iPhoneの「ファイル」アプリからHTMLを直接開くだけでは、ホーム画面アプリとしてのインストールやオフライン機能が正常に動作しないことがあります。
ホーム画面に追加するには、これらのファイルをHTTPS対応のWebホスティングにアップロードし、そのURLをSafariで開いて「共有」→「ホーム画面に追加」を選んでください。

データ:
画像はIndexedDB、設定と獲得記録はlocalStorageに保存されます。基本的に同じブラウザ・同じ端末内の保存です。SafariのWebサイトデータ消去などで失われる可能性があるため、アプリ内の「バックアップを書き出す」を定期的に使ってください。
